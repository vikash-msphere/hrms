1. Sheet settings — A4-65 (38.1 × 21.2mm)

Layout assumes the standard A4-65 grid (5 cols × 13 rows, 4.75mm side margin, 10.7mm top/bottom margin). If the print lands slightly off on the real sticker sheet, nudge the offsets here instead of editing CSS.
In the print dialog: set Margins to None, Scale to 100%, and turn off headers/footers.

2. Tag details

Auto-generated (prefix + category + next number). Editable before adding if you need a specific ID.
Left-click an empty slot to choose where this tag prints (a slot is auto-selected for you). Right-click an empty slot to mark it "used" — do this for labels already peeled off a partially-used sheet, so nothing prints on top of them. Right-click a "used" slot again to undo.

3. Settings

Switch to the URL template once the HRMS endpoint exists — old tags stay valid as long as the ID inside the URL matches.
